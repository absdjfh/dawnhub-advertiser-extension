Installing the ZIP by hand

Only if you can't use the Chrome Web Store

Load it into Chrome

  1. Download the ZIP above and extract it to a folder you'll keep.
  2. Open chrome://extensions and switch on Developer mode.
  3. Select Load unpacked and choose the extracted folder.

Keeping it up to date

  1. A ZIP install doesn't update on its own. Check back here for new versions.
  2. To update, extract the new ZIP over the same folder.
  3. Then select the reload icon on the extension's card in chrome://extensions.
